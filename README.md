# 배관 용접 관리 시스템

건설현장 배관 ISO/Cutting Plan 기반 용접·비파괴검사(NDE) 관리 웹앱.
**인터넷 없이** `index.html`을 더블클릭하면 브라우저에서 바로 열립니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 대시보드 (첫 화면) | 총 Dia-Inch / 완료 Dia-Inch(NDE 합격 기준) / NDE 합격률 / 불합격 건수 / 스풀 입고율 / 오늘 실적 KPI + 계통별 진행 스택바 + 용접사별 불량률 + 라인별 현황 + 불합격 목록(클릭 → 3D 이동) |
| 계통 선택 | 헤더의 계통 드롭다운(예: FG1 — Fuel Gas)으로 그 계통 라인들만 모아서 표시. 라인번호에서 계통 코드 자동 인식 |
| 3D 배관 뷰 | ISO 도면 기반 3D 재구성. 드래그 회전 / 휠 확대 / 우클릭 이동. 라인에 `origin`(전역 E/N/EL) 입력 시 실좌표로 연결 배치 |
| 단계별 색상 | 미착수(회색) → 스풀입고(청록) → Fit-up(파랑) → 용접완료(주황) → NDE합격(초록) → **NDE불합격(빨강 깜빡임)** |
| Shop/Field 구분 | ●구 = Shop 용접(공장 스풀), ⬡팔면체 = Field 용접(현장) |
| 실적 입력 | 조인트 클릭(3D 또는 표) → Fit-up일 / 용접일 / 용접사 / NDE종류·일·결과 입력, 자동 저장 |
| Repair 이력 | 불합격 → Repair 추가(R1, R2...) → 보수용접일·용접사·재검사일·재검결과 추적 |
| 스풀 관리 | 스풀(공장) 탭에서 스풀별 입고일 입력 → 해당 Shop 조인트 자동 "스풀입고" 표시 |
| 날짜 조회 | 조인트 탭 날짜 필터로 특정 날짜의 용접/NDE 실적 조회 |
| 용접사 통계 | 통계 탭: 용접사별 용접건수 / NDE판정 / 불합격 / **불합격률** (Repair 포함, 5%↑ 빨간 표시) |
| 엑셀 내보내기 | 조인트현황 · 스풀입고 · 용접사통계 3개 시트 .xlsx 저장 |
| 백업/복원 | JSON 백업 파일 저장/가져오기 (PC 간 데이터 이동용) |

## 데이터 저장 방식

- 입력 데이터는 브라우저 **localStorage**에 자동 저장됩니다 (같은 PC·같은 브라우저에서 유지).
- 다른 PC로 옮기거나 안전하게 보관하려면 **백업(JSON)** 버튼으로 파일을 저장하고, 다른 PC에서 **가져오기** 하세요.
- 공식 보고용은 **엑셀 내보내기**를 사용하세요.

## 라인 추가 방법

`data.js`의 `PIPE_DATA.lines` 배열에 라인을 추가합니다.

```js
{
  id: "라인번호",            // 예: "100-FG1-GK2-00007"
  dn: 100, od: 114.3,        // 구경(DN), 외경(mm)
  material: "A106-B SMLS",
  from: "출발점", to: "도착점",
  commodity: "FUEL GAS", ndt: "RT 100%", drawing: "도면번호",
  nodes: [                   // 배관 경로 [E(동), N(북), EL(고도)] mm — ISO 치수 따라 꺾이는 점마다
    [0, 0, 3000],
    [-500, 0, 3000],
    ...
  ],
  spools: ["S01", "S02", ...],
  joints: [                  // type: "S"=Shop(공장), "F"=Field(현장)
    { no: 1, type: "S", spool: "S01", pos: [0, 0, 3000] },
    { no: 2, type: "F", spool: "S01/S02", pos: [-500, 0, 3100] },
    ...
  ]
}
```

※ 현재 탑재된 2개 라인(`150-FG1-GK1-00006`, `80-FG1-GB4-00005`)의 3D 경로는
ISO 도면 치수·고도 기준의 근사 재구성입니다. 조인트 수·스풀 구성·Shop/Field 구분은 도면과 동일합니다.

## 파일 구성

- `index.html` — 메인 화면 (이 파일을 열면 실행)
- `app.js` — 로직 (3D, 입력, 통계, 엑셀)
- `data.js` — 라인/스풀/조인트 데이터
- `libs/` — Three.js, OrbitControls, SheetJS (오프라인 동작용 내장)
